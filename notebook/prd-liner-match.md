# PRD - Liner (主播社交匹配)

## 核心定位
关播后的「主播版 Tinder」，用 AI 匹配志同道合的创作者。

## 页面/流程
1. **直播结束触发页 (Live Summary / Home)**
   - 完整还原关播数据总结页面（Live Summary），包含时长、收益、旅程阶段、粉丝团等模块。
   - 界面语言：English。
   - 页面右下角增加一个“跳动的小火苗”悬浮球，作为 Liner 匹配流程的入口。
   - 点击小火苗后，跳转至 Liner 匹配界面。

2. **匹配卡片交互页 (Match Cards)**
   - 卡片叠放（Tinder-style），支持左右滑动、双击。
   - 包含：头像、昵称、高光视频片段（循环播放）、关系标签、共同/互补特质、AI 推荐理由。
   - 底部操作区：左滑（不感兴趣）、右滑（喜欢）、双击（超级喜欢）。
   - 顶部/侧边有进度指示（如 1/5）。
   - 交互反馈：滑动时的 Like/Nope 印章效果。

3. **匹配成功庆祝页 (Match Celebration)**
   - 全屏庆祝特效（Match!）。
   - 展示双方头像。
   - 自动跳转或有按钮进入私聊页面。

4. **私聊页 (Chat)**
   - AI 生成破冰话术（Icebreaker）。
   - 顶部显示 Match 标志或提示语。

## 视觉与动画
- 使用 framer-motion 实现卡片的拖拽和物理动画。
- 科技感与社交感的 UI。
- 小火苗悬浮球增加跳动（Bounce）动画，吸引用户点击。
